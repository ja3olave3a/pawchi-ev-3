# Pawchi – Evaluación Parcial 3 (FullStack 2)

Tienda de blind boxes de perritos para coleccionar.

## Estructura
- `pawchi/`: backend (Spring Boot, Maven, Java 21)
- `pawchi-front/`: frontend (React + Vite, atomic design)

## Cómo ejecutar
Backend:
    cd pawchi
    ./mvnw spring-boot:run (en Windows: mvnw.cmd spring-boot:run, y en PowerShell .\mvnw.cmd spring-boot:run)
Corre en http://localhost:8080

Frontend:
    cd pawchi-front
    npm install
    npm run dev
Corre en http://localhost:5173
