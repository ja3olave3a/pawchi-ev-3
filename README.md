# Pawchi – Evaluación Parcial 3 (FullStack 2)

Tienda de blind boxes de perritos para coleccionar.

## Estructura
- `pawchi/`: backend (Spring Boot, Gradle, Java 21)
- `pawchi-front/`: frontend (React + Vite, atomic design)

## Cómo ejecutar
Backend:
    cd pawchi
    ./gradlew bootRun      (en Windows: gradlew.bat bootRun)
Corre en http://localhost:8080

Frontend:
    cd pawchi-front
    npm install
    npm run dev
Corre en http://localhost:5173
